🏨 Hotel Booking and Reservation System

A Hotel Booking and Reservation System built with Core Java (Swing + AWT), integrated with MySQL for database management. This project was developed using NetBeans IDE (Jan 2025) to streamline hotel operations such as reservations, cancellations, customer management, and room availability tracking.

✨ Features

Room Booking & Reservation Management

Handle new reservations, cancellations, and update booking status.

Customer Management

Add and manage customer details.

Check-in / check-out functionalities.

Room Availability Tracking

Display available and occupied rooms in real time.

Dynamic interface to help hotel staff manage bookings efficiently.

Database Integration

Persistent storage and retrieval of data using MySQL.

🛠️ Tech Stack

Frontend & Logic: Core Java (Swing + AWT)

Database: MySQL

IDE Used: NetBeans

⚙️ Installation & Setup

Setup Database

Install MySQL and create a database (e.g., hotel_db).

Import the SQL file (hotel_db.sql) provided in the repository.

Configure Database Connection

Update database credentials (username, password, database name) in the Java code (DBConnection.java or equivalent).

Run the Project

Open the project in NetBeans IDE.

Build and run the application.
